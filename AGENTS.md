# Design workflow

For relevant frontend work, consult the project-local skills in `.agents/skills/`:

1. Use `frontend-design` to guide the overall design and build.
2. Use `ui-ux-pro-max` and `design-taste-frontend` as appropriate for UI/UX and visual styling.
3. Use `impeccable` and `web-design-guidelines` as appropriate to review and refine the result.

Read each relevant `SKILL.md` and its referenced material before applying it. Adapt guidance to the actual product, the user's brief, accessibility, and existing project conventions; resolve conflicting advice accordingly. Review skill scripts before executing them. Vercel's guidelines skill references raw.githubusercontent.com, which may be unavailable in restricted environments; if necessary, retrieve the same file through the GitHub API instead.
